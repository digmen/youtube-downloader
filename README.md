# 🎬 YouTube Downloader Bot

<img src="avatar.png" width="120" align="right">

Telegram-бот, который скачивает видео (или только звук) с YouTube в лучшем
доступном качестве и присылает файлом прямо в чат.

Написан на **Node.js**, работает под **PM2**, движок скачивания — **yt-dlp** +
**ffmpeg**. Большие файлы (до 2 ГБ) идут через собственный локальный Bot API
вместо облачного — обычный лимит Telegram для бота 20/50 МБ на этом не режет.

---

## 🔒 Доступ по запросу

Бот не публичный. Пишет незнакомый человек — владельцу приходит карточка с
кнопками **«Разрешить» / «Отклонить»**; решение сохраняется на диске
(`data/allowed.json`) и переживает рестарт. Никакой открытой регистрации —
каждый новый человек утверждается лично, вручную, одной кнопкой
(см. `src/access.js`).

## ✨ Возможности

- 📹 Видео в лучшем качестве, укладывающемся в лимит — mp4, готовый к
  проигрыванию в Telegram без перекодирования на стороне клиента.
- 🎵 Только звук — допиши `audio` рядом со ссылкой.
- 🔗 Понимает `youtube.com/...`, `m.youtube.com`, `music.youtube.com`, `youtu.be`.
- 🧵 Очередь загрузок (по умолчанию — по одной), чтобы не грузить сервер, на
  котором рядом крутятся другие сервисы.
- 💬 Понятные сообщения об ошибках вместо «сырых» логов yt-dlp (приватное
  видео, регион, возрастное ограничение, трансляция и т.д.).
- 🗑 Файл удаляется сразу после отправки — диск не копится.

## 🤖 Команды

| Команда | Кто может | Что делает |
|---------|-----------|-----------|
| `/start`, `/help` | допущенные | приветствие и инструкция |
| `/ping` | допущенные | проверка, что бот жив |
| `/stats` | только владелец | аптайм, успешные/ошибочные загрузки, очередь |
| `/users` | только владелец | список, кому разрешён доступ |
| `/revoke <id>` | только владелец | отозвать доступ у конкретного id |

## 🏗 Как это устроено

```
Пользователь → Telegram → бот (grammY, long polling)
                              │
                    доступ по запросу (access.js)
                              │
                        очередь (p-queue, concurrency=1)
                              │
                    yt-dlp + ffmpeg/ffprobe → tmp/<jobId>/
                              │
                  видео/звук → отправка → удаление файла
```

### Структура

| Файл | Назначение |
|------|-----------|
| `src/config.js` | чтение `.env`, значения по умолчанию |
| `src/urls.js` | валидация и извлечение YouTube-ссылок (whitelist доменов) |
| `src/access.js` | доступ по запросу: список разрешённых + карточки владельцу |
| `src/downloader.js` | вызов yt-dlp через `execFile` (без shell), ffmpeg/ffprobe |
| `src/errors.js` | перевод ошибок yt-dlp в понятные пользователю сообщения |
| `src/queue.js` | очередь загрузок |
| `src/bot.js` | хендлеры grammY, команды, отправка контента |
| `src/index.js` | запуск, graceful shutdown |

## 🚀 Быстрый старт (локально)

Нужны: **Node.js 18.15+**, **yt-dlp** и **ffmpeg** (включает ffprobe).

```bash
git clone https://github.com/digmen/youtube-downloader.git
cd youtube-downloader
npm install

cp .env.example .env      # впишите BOT_TOKEN и OWNER_ID
npm start                 # или: npm run dev
```

Свой Telegram-id узнать у [@userinfobot](https://t.me/userinfobot).

## 📦 Большие видео — локальный Bot API

Обычный `api.telegram.org` режет боту приём/отдачу до 20/50 МБ. Чтобы
отправлять файлы до 2 ГБ, поднимите свой [telegram-bot-api](https://github.com/tdlib/telegram-bot-api):

```bash
docker run -d --name tg-bot-api --restart unless-stopped \
  -p 127.0.0.1:8082:8081 \
  -e TELEGRAM_API_ID=<api_id> -e TELEGRAM_API_HASH=<api_hash> -e TELEGRAM_LOCAL=1 \
  -v /path/botapi:/var/lib/telegram-bot-api \
  aiogram/telegram-bot-api:latest
```

`api_id`/`api_hash` — на [my.telegram.org](https://my.telegram.org). Дальше в
`.env`: `TELEGRAM_API_ROOT=http://127.0.0.1:8082`. Один такой контейнер можно
использовать сразу для нескольких ботов.

## ⚙️ Настройки (`.env`)

| Переменная | По умолчанию | Что делает |
|-----------|--------------|-----------|
| `BOT_TOKEN` | — (обязательно) | токен бота от @BotFather |
| `OWNER_ID` | — (обязательно) | ваш Telegram-id: всегда допущен, получает карточки запросов доступа |
| `ADMIN_CHAT_ID` | — | Telegram-id для алертов (обычно = `OWNER_ID`) |
| `YTDLP_PATH` / `FFMPEG_PATH` / `FFPROBE_PATH` | из `PATH` | пути к бинарникам |
| `TMP_DIR` | `./tmp` | папка временных файлов |
| `QUEUE_CONCURRENCY` | 1 | сколько загрузок одновременно |
| `DOWNLOAD_TIMEOUT_SEC` | 600 | таймаут одной загрузки |
| `MIN_FREE_DISK_MB` | 2000 | мин. свободного места для старта загрузки |
| `MAX_FILESIZE_MB` | 1900 | потолок размера файла |
| `TELEGRAM_API_ROOT` | — | свой Bot API (для файлов > 50 МБ); пусто = облачный |

## 🎛 Управление (PM2)

```bash
pm2 start ecosystem.config.cjs
pm2 logs youtube-bot
pm2 restart youtube-bot
```
